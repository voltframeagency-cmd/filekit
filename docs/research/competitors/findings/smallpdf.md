# Smallpdf Competitor Audit Findings

## 1. Overview
- **Slug**: `smallpdf`
- **URL**: `https://smallpdf.com`
- **Category**: Premium PDF & Document Workspace
- **Audited Tools**: Compress PDF, Merge PDF, Edit PDF, PDF Converter.

## 2. Interaction & Workflow Analysis
- **Clicks to Upload**: 1 click (`Choose Files` or central drop area).
- **Clicks to Process**: 1 click (`Compress` / `Convert`).
- **Clicks to Download**: 1 click (`Download`).
- **Source File Retention**: Requires re-uploading or Pro subscription to switch operations.
- **Live Preview**: PDF page previews rendered in browser.
- **Batch Support**: Available only for Pro subscribers.

## 3. Visual System & Components
- **Color Palette**: Electric Blue (`#1E6091`), Multi-color pastel accents (Yellow, Pink, Emerald, Cyan).
- **Typography**: Modern rounded sans-serif (`Circular`/`Inter`).
- **Card System**: Airy 3-column tile layout with soft drop shadows and floating abstract shapes.

## 4. Monetization & Trust Communication
- **Monetization Trap**: **Strict 2-task daily free limit**. After 2 operations, a hard paywall blocks access and forces a 7-day free trial.
- **Trust Messaging**: Emphasizes ISO 27001 certification and automatic TLS encryption / deletion timers.

## 5. FileKit Recommendations
- **ADAPT**: Approachable color accents and friendly micro-copy.
- **AVOID**: Daily task count hard paywalls and locked basic batch processing.
