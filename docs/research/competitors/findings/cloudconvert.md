# CloudConvert Competitor Audit Findings

## 1. Overview
- **Slug**: `cloudconvert`
- **URL**: `https://cloudconvert.com`
- **Category**: High-Precision Conversion API & Web Utility
- **Audited Tools**: Image Converter, PDF to Image, Image to PDF, Document Converter.

## 2. Interaction & Workflow Analysis
- **Clicks to Upload**: 1 click (`Select File`).
- **Clicks to Process**: 2 clicks (Select format node + `Convert`).
- **Clicks to Download**: 1 click (`Download`).
- **Status Indicators**: Excellent explicit stage tracking (`Uploading` → `Processing` → `Finished`).

## 3. Visual System & Components
- **Color Palette**: Dark Slate (`#18181B`), Crimson Red (`#E11D48`), Clean White container card.
- **Graphic Design**: Developer-focused aesthetic, interactive `[Format A] -> [Format B]` node selector in hero.

## 4. Monetization & Trust Communication
- **Monetization**: Free quota of 25 conversions/day; API subscription tiers.
- **Trust Messaging**: ISO 27001 certified, explicit data security disclosure (*"Files are removed after processing"*).

## 5. FileKit Recommendations
- **ADOPT**: Clear stage label progress indicators (`Inspecting` → `Processing` → `Verifying`).
- **ADAPT**: Sleek dark accent themes and format selector UI.
