# Sejda Competitor Audit Findings

## 1. Overview
- **Slug**: `sejda`
- **URL**: `https://sejda.com`
- **Category**: Visual PDF Editor & Suite
- **Audited Tools**: Merge PDF, Split PDF, Delete PDF Pages, Rotate PDF, Compress PDF.

## 2. Interaction & Workflow Analysis
- **Clicks to Upload**: 1 click (`Upload PDF files`).
- **Clicks to Process**: 1 click (`Merge PDF` / `Perform Task`).
- **Clicks to Download**: 1 click (`Download`).
- **Live Preview**: Highly polished visual thumbnail grid for page reordering, rotation, deletion, and page selection.

## 3. Visual System & Components
- **Color Palette**: Mint Green (`#3B82F6` / `#10B981`), Crisp White Background.
- **UI Architecture**: Refined drag-and-drop page grid with hover tooltips and selection checkboxes.

## 4. Monetization & Trust Communication
- **Monetization Trap**: Strict **3 tasks per hour ceiling** (or 50MB limit). Reaching limit triggers an abrupt paywall modal.
- **Trust Messaging**: Automated 2-hour file deletion guarantee.

## 5. FileKit Recommendations
- **ADAPT**: Visual thumbnail page grid for PDF Organization Suite (`/merge-pdf`, `/split-pdf`, `/rotate-pdf`, `/delete-pdf-pages`).
- **AVOID**: Hourly task ceiling paywalls.
