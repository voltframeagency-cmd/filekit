# FileKit Individual UI Assets v1

These screens replace the earlier combined master-board image.

Each file contains exactly one interface state so implementation agents
do not have to infer layouts from a collage.

## Included

1. Desktop homepage
2. Empty upload workspace
3. Local-safe inspected file
4. Honest phase-based processing
5. Secure server fallback consent
6. Verified result
7. Transparent result-first paywall
8. Mobile local-safe inspected state
9. Arabic RTL local-safe inspected state

## Production decisions included

- No full pricing table on the homepage
- Result-first monetization
- €4.99 single premium export
- €7.99 non-renewing 24-hour pass
- €9.99/month Pro
- No preselected plan
- TLS language
- Explicit server-processing consent
- No fixed file-size routing rule
- Source deletion after processing
- Output expiry within 24 hours
- No fake progress percentage
- Green reserved for verified local/success states
- Indigo reserved for temporary server processing

Both editable SVGs and rendered PNGs are included.
