# FileKit Brand Assets v3 — Polished Reconstruction

This package replaces the earlier detached folded-corner geometry.

## Fold correction
The document silhouette now ends at the folded corner. The blue fold:
- begins exactly on the top paper edge,
- follows the diagonal paper cut,
- uses a rounded inner return,
- meets the right page edge without a duplicated navy/white bracket,
- remains consistent across transparent, monochrome, inverted, app-icon, and favicon variants.

## Included
- Clean production SVG marks
- Outlined SVG wordmarks and horizontal logos
- Transparent PNGs
- Monochrome and inverted variants
- App icons
- Favicons and `.ico`
- Web app manifest
- JSON, CSS, Tailwind v4, and TypeScript brand tokens
- Editable and outlined identity boards
- Original raster reference and fold comparison

## Production guidance
- Use the color horizontal logo on warm-white or white surfaces.
- Use the inverted logo on Midnight Ink backgrounds.
- Use the navy app icon for default product icons.
- Use monochrome variants where production constraints require one color.
- Reserve success green for verified success states.
- Do not redraw or detach the folded corner.
- No font files are included.
